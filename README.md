# framer-to-astro-demo

A test repository for openfabriq's Framer to Astro factory: it moves the public Framer template demo at https://conversion.framer.media to an Astro site, here.

No CMS export: the template's blog is read on its published pages.

To start: open an issue "Migrate https://conversion.framer.media" and add `migration:discover`.
